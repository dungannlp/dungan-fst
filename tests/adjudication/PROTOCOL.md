# Independent precision adjudication: annotation protocol

## Why this exists

The automated precision check (`tests/precision.py`) is **closed over a single
source**: the reference readings are derived from the same Yanshansin
dictionary from which the analyzer's stems were built. It therefore catches
implementation errors (a rule that failed to fire, lexicon–reference drift)
but **cannot** detect errors shared by both sides — an inaccuracy of the
dictionary itself, or a linguistic decision applied uniformly to the lexicon
and the reference alike (see the paper's section "Core Completeness and
Evaluation").

Only the judgment of an **independent party** — a native speaker of Dungan or
a Dungan-studies specialist — can break that loop. This worksheet is the
instrument for that judgment.

## The file

`precision_worksheet.csv` — 100 word-forms from real Dungan text (Dungan
Wikipedia articles, licence CC BY-SA). The sample is **deliberately biased**
towards affixed word-forms and word-forms with several readings: that is where
correctness is genuinely in question. Bare dictionary stems (trivially
correct) are mostly excluded, so the score obtained from this sheet measures
the **hard cases**; it is not directly comparable to the automated 100%
obtained on the easier 104-form set.

Columns:

| column | content |
|---|---|
| no. | row number |
| word form | the word form to judge |
| context | ±5 words around the first occurrence (for disambiguation) |
| analyzer readings (all) | every reading the analyzer returns, separated by ` \| ` |
| correct reading present? (yes/no) | **filled in by the expert** |
| if 'no': correct reading / comment | **filled in by the expert** |

## How to annotate

For each row:

1. Read the word form in its context.
2. Look at the analyzer's readings. Notation: `<n>` noun, `<nn>`/`<an>`
   inanimate/animate, `<np>` proper noun, `<vblex>` verb, `<adj>` adjective,
   `<adv>` adverb, `<prn>` pronoun; `<gen>` genitive, `<loc>` locative,
   `<pl>` plural, `<pst>` perfective, `<prog>`/`<fut>` aspect–tense markers,
   `<t1>…<t3>` lexical tone.
3. In the "correct reading present?" column enter **yes** if at least one of
   the proposed readings is contextually correct (correct lemma, part of
   speech and grammatical tags); otherwise **no**.
4. If "no", state briefly in the last column the correct reading or the
   reason (wrong lemma, wrong part of speech, an extra or missing marker,
   etc.). Remarks about *extra* wrong readings present alongside a correct
   one are also valuable — add them to the comment.

## How to score

- **Recall (a correct reading is present):** the share of rows marked
  "yes" = N(yes) / 100. This is precision in the sense of `precision.py`,
  but obtained **independently** of the source dictionary. Any gap from the
  automated 100% points to errors the closed test could not see.
- **Ambiguity:** the mean number of readings per row (from the readings
  column), and the share of rows in which only one of several readings is
  correct, characterise overgeneration.

## Reproducibility and extension

The sheet is generated by `tests/build_adjudication.py [gan|shaanxi]` with a
fixed random seed, so a rerun on the same corpus and the same analyzer build
reproduces the same 100 forms; after a lexicon change the readings — and,
through the stratification, possibly the sample itself — change with the
build. The same procedure can be pointed at the **held-out** texts (see
`tests/heldout.py`), making both the text and the judgment independent
(double independence). That remains future work requiring a native speaker.
