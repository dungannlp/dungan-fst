# Precision gold set for the Dungan FST.
# Each line: TOKEN <TAB> CORRECT_ANALYSIS <TAB> HANZI <TAB> GLOSS
# The CORRECT_ANALYSIS is the single contextually-correct reading, determined
# from the hanzi (which disambiguates the morpheme). We score whether the
# analyser PRODUCES this reading (recall) and how many OTHER readings it adds
# (ambiguity). Tone tags are included where the dictionary attests them.
#
# CIRCULARITY CAVEAT (read before citing the 100% figure): this measurement is
# a CLOSED LOOP on one source. The Yanshansin dictionary feeds BOTH the
# analyser's stems (stem, POS-from-gloss, tone-from-marks, hanzi) AND these
# gold labels (the "correct" reading is fixed by the same hanzi). The same
# segmentation / POS / tone decisions sit on both sides. So a match tests
# INTERNAL CONSISTENCY, not correctness: it catches implementation bugs (a
# twol rule that misfires, a typo in a continuation class, lexicon/gold drift)
# but CANNOT catch errors shared by both sides (a wrong dictionary entry or a
# wrong linguistic decision applied uniformly). Breaking the loop needs an
# INDEPENDENT gold (another dictionary, a separately annotated corpus) and/or
# an independent adjudicator (native speaker / Dungan specialist). The point is
# not that AI tooling assisted the markup, but that the loop is closed: a human
# building analyser and gold from one dictionary would get the same result.
# (Coverage is free of this loop: it runs on external text and scores only
# recognition.)
#
